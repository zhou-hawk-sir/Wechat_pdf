# 聊天记录导出工具

从本机微信 4.x 的本地数据中导出聊天记录（单聊与群聊），支持 HTML、CSV、JSON、TXT、PDF 五种格式，
图片解密成 jpg/png、语音转成 wav 一并拷出，文件附件保留原始文件名。

本工具只在你自己的电脑上本地运行，不联网、不上传任何数据，仅用于导出你自己的聊天记录。

## 功能

- 三步式界面：获取密钥 → 选会话 → 导出。
- 自动从运行中的微信进程读取数据库密钥，不需要重启微信，也不需要任何第三方组件。
- 支持单聊与群聊，会话列表可搜索、多选。
- 导出格式：HTML（微信气泡样式）、PDF（同一版式，经 Chrome/Edge 无头打印）、CSV、JSON、TXT。
- 媒体还原：图片（AES 解 .dat）、语音（SILK 转 WAV）、视频、文件附件。
- 媒体按 `媒体\<会话名>\` 分目录存放，文件名带消息时间，便于对照。

## 环境要求

- Windows 10/11
- 已登录的微信 4.x（已在 4.2.0.11 实测通过），导出时保持运行（密钥只在运行时存在于内存）
- **用普通权限运行**，不要右键「以管理员身份运行」。读取微信内存不需要提权，
  而浏览器在管理员权限下会降权重启，无头打印会静默失败（返回码 0 但不生成文件）
- PDF 需要本机装有 Chrome 或 Edge（系统级、用户级安装都能识别，
  注册表里登记过的自定义安装目录也能识别；两个都装时逐个尝试）

数据目录自动查找，不需要手动指定：环境变量 → 上次结果缓存 → 用户文档 →
注册表旧路径 → 各盘符根目录 → 逐个固定盘按目录名扫三层。微信把「文件管理」
设到 `D:\Tencent\Documents` 这类位置也能找到。只有全部落空时才需要点界面上的
「数据目录」手动选一下 `xwechat_files` 文件夹（选错层级会自动纠正）。

出问题时点右上角「环境自检」，它会输出微信版本、密钥扫描结果、浏览器清单，
并**真的打印一份小 PDF** 验证打印链路，把整段文本发回来就能定位问题。

## 直接使用 exe

打包好的成品在 `release\聊天记录导出.exe`，下载后双击即可运行，目标机器不需要装 Python。

自己重新打包：

```
python build_exe.py
```

产物为 `dist\聊天记录导出.exe`，单文件，目标机器不需要装 Python。分发给别人时只发这一个 exe。

## 从源码运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
wechat_log
```

或不激活环境：

```bash
.venv\Scripts\python.exe -m wechat_log
```

跑测试与打包工具：`pip install -e ".[dev]"`。

> `pilk` 是 C 扩展，pip 安装时需要本机有 C 编译器；装不上时语音会退化为保留 `.silk` 原文件，
> 其余功能不受影响。

## 导出物结构

```
导出结果\
├─ 杨浩.pdf / 杨浩.html / 杨浩.txt / 杨浩.csv / 杨浩.json
└─ 媒体\杨浩\
   ├─ 20250907_190325_02.jpg
   ├─ 20250905_225830_01.wav
   └─ 附件1 2024年邮爱奖学金申请表.docx
```

## 原理简述

- 数据库：SQLCipher 兼容格式，页大小 4096、保留区 80 字节；密钥为 32 字节原始值。
- 取密钥：微信把 `x'<64位hex密钥><32位hex盐>'` 这一字面量按 32 字节掩码异或后留在内存里，
  扫描进程内存还原即可；掩码失配时退化为用库文件里的盐反查。
- 图片：`.dat` 由 `md5(uin + wxid)[:16]` 派生的 AES-128-ECB 加尾段单字节异或封装；
  推导出的密钥记在账号目录的 `.wechat_log_image_key.json` 里，换机器可直接复用。
- 语音：`message/media_*.db` 的 `VoiceInfo` 表，SILK 编码，用 `pilk` 转 WAV。

## 已知限制

- 图片/语音只还原本机已下载过的部分，微信按需同步，久远的媒体可能本机没有。
- 视频依赖 hardlink 索引匹配，个别消息可能只有缩略图或无法定位。
- 表情包（emoji）暂以 `[表情]` 占位。
- 群聊中极少数发送者可能显示为数字 ID（对应名称映射缺失）。
- 密钥扫描依赖内存中的字面量布局，微信大版本升级后可能需要更新（可用 `WECHAT_LOG_KEY_MASK`
  指定新掩码，或直接用「导入密钥」手动粘贴）。

### 关于图片密钥与换机器

图片的 `.dat` 用 `md5(uin + wxid)` 作密钥，`uin` 是微信账号的内部数字编号。微信**不把它写进
`xwechat_files`**，只在它自己的程序数据目录 `%APPDATA%\Tencent\xwechat\*\kvcomm\*.statistic`
的文件名里露出。所以：

- 首次成功导出后，程序会把算好的密钥记一份到 `xwechat_files\<账号目录>\.wechat_log_image_key.json`，
  这份缓存跟着数据目录走。之后只拷 `xwechat_files` 到别的电脑也能直接解图，不必依赖 `%APPDATA%`。
- 如果两边都没有（比如从没在本机跑过、直接拷了别人的数据），可以用环境变量 `WECHAT_LOG_UIN`
  指定 uin，例如 `set WECHAT_LOG_UIN=1023634050`。
- 语音、视频、文件附件不依赖 uin，不受影响。
